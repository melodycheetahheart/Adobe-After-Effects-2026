## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Templates:** Import the motion graphics templates from `/templates` via After Effects' "Import" function.
   - **Scripts:** Run the automation scripts from `/scripts` via File > Scripts > Run Script File.
   - **Presets:** Apply the animation, color grading, and export presets from `/presets`.
4. Restart After Effects and follow the documentation to apply your configurations.
